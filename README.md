# Jeu de devinettes en Python

## Description

Ce projet est un jeu de devinettes développé en Python.

Le programme génère aléatoirement un nombre secret compris entre 1 et 100. Le joueur dispose de cinq tentatives pour trouver le nombre.

Après chaque proposition, le programme fournit des indices permettant au joueur de savoir s'il est proche ou éloigné de la bonne réponse.

## Fonctionnalités

- Génération aléatoire d'un nombre secret.
- Limitation du nombre d'essais à cinq tentatives.
- Indication lorsque le nombre proposé est trop grand.
- Indication lorsque le nombre proposé est trop petit.
- Système d'aide basé sur l'écart avec le nombre secret.
- Affichage du nombre de tentatives utilisées.
- Révélation du nombre secret en cas d'échec.

## Technologies utilisées

- Python 3
- Module Random

## Concepts utilisés

- Fonctions
- Boucles `while`
- Conditions imbriquées
- Variables
- Gestion des entrées utilisateur
- Génération de nombres aléatoires

## Objectif pédagogique

Ce projet a été réalisé dans le cadre de mon apprentissage de Python afin de pratiquer les fonctions, les boucles, les conditions et la manipulation des nombres aléatoires.
